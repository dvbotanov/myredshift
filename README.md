# Вселенная. История расширения

Научно-популярный сайт об эволюции представлений о расширении Вселенной. Одна страница: стартовый экран на фоне Сверхглубокого поля Хаббла, затем обычная вертикальная прокрутка ведёт по горизонтальной экспозиции из 20 сцен, внизу — шкала лет открытий с портретами и приборами. Техническое задание — [BRIEF.md](BRIEF.md), исследовательская база — `research/`.

**Научные данные проверены: 19 сентября 2026.** Дата зашита в `tools/build.py` и `research/cosmology-data.json` (`last_checked`); обновлять её следует только после реальной повторной проверки источников.

## Запуск

Нужны только macOS-инструменты: `python3` (3.9+) и `sips`. Node не требуется.

```bash
python3 tools/build.py            # собрать dist/index.html (один самодостаточный файл)
python3 -m http.server 8765 --directory dist   # открыть http://localhost:8765
```

Или одной командой: `tools/serve.sh`. Готовый `dist/index.html` можно открыть и просто двойным щелчком: все данные, шрифты и изображения встроены в него (≈8,1 МБ).

## Проверки

```bash
tools/run_tests.sh   # юнит-тесты геометрии прокрутки (jsc) + целостность данных
```

- `tests/geometry.test.js` — преобразование scrollY ↔ x, границы первой/последней сцены, позиции маркеров (25 проверок).
- `tools/check_data.py` — ссылки сцена → событие → источник → изображение → сущность, 43 события E001–E043, отсутствие Lorem ipsum, статус прав на изображения, единицы H₀.

## Как добавить

**Событие.** Добавить запись в `research/cosmology-data.json` → `timeline` (id `E044`, `date_label`, `year_start/end`, `title`, `body_ru`, `source_ids`, `date_precision`, `status`) и источники в `sources`. Событие автоматически появится в полной хронологии. Чтобы показать его в сцене — добавить id в `researchEventIds` нужной сцены в `src/data/scenes.json`.

**Портрет или прибор.** 1) Добавить запись в `tools/wanted_assets.json`: `id`, `commons` (точное имя файла на Wikimedia Commons), `kind`, `subject`, `altRu`, `captionRu`, `focal` (точка кадрирования), при необходимости `thumbCrop`. 2) `python3 tools/fetch_assets.py` — скачает файл, проверит лицензию через API, сделает большую версию и миниатюру, обновит `src/data/assets.json`. 3) Добавить сущность в `src/data/entities.json` с `assetId` и `relatedEventIds`, вписать её в `entityIds`/`secondaryAssetIds`/`markers` сцены. Если изображения нет — `assetId: null`, будет подписанный резервный вариант.

**Новый результат H₀.** Добавить запись в `hubble_measurements` (`value`, `error_minus/plus`, `unit`, `method`, `model_or_calibration`, `version`, `note`, `source_ids`). Метод должен быть в `METHOD_GROUP` в `01-data.js` (иначе попадёт в группу локальных). Если результат коррелирует с уже имеющимися, добавить его id в `CORRELATED` там же — точки получат общую скобку и пометку «не независимые».

**Новая сцена.** Объект в `scenes.json` с уникальным `id`, `order`, `chapterId`, текстами, `heroAssetId`, `markers` и `diagramId` (или `null`); добавить `id` в `sceneIds` главы. Схемы регистрируются в `REG` в `03-diagrams.js`.

После любого изменения: `tools/run_tests.sh && python3 tools/build.py`.

## Что проверено

Во встроенном браузере (Chromium) на размерах 1440×900, 1920×1080, 1366×768, 1024×768, 375×812:

- прокрутка вниз двигает экспозицию вправо, назад — возвращает; остановка останавливает движение;
- координаты: T=27 360, S=27 360, высота секции H+S; первая и последняя сцены достижимы, конец страницы с источниками достижим;
- прямая ссылка `#scene=…` открывает сцену; «Далее» добавляет запись истории, «назад» браузера возвращает на предыдущую сцену;
- диалог «Подробнее» не сдвигает страницу и возвращает фокус; фон под диалогом не прокручивается;
- переключение «Вид чтения» сохраняет текущую сцену; ширина <700 или высота <650 → режим чтения; `prefers-reduced-motion` → режим чтения по умолчанию;
- нет горизонтальной прокрутки всей страницы; на 1440×900, 1920×1080 и 1366×768 ни одна текстовая колонка не переполняется;
- сцены дальше соседней помечены `inert`, их кнопки и маркеры шкалы не получают фокус;
- консоль без ошибок.

Safari и Firefox в этой среде недоступны — поддержка не заявляется до ручной проверки. Масштаб браузера 200 % и печать проверены только по коду (медиазапросы и `@media print`), не визуально.

## Ограничения первой версии

- Файл `dist/index.html` весит ≈8,1 МБ, потому что по решению заказчика это один самодостаточный файл со встроенными изображениями. Ориентир ТЗ в 1,5–2 МБ при таком формате недостижим; ленивая загрузка изображений не даёт эффекта.
- Изображения не подобраны (показан подписанный резервный вариант): Роберт Герман, Кент Форд, телескоп SDSS, BOOMERanG. Портрет Весто Слайфера — кадр из группового снимка 1905 года. Гамов — небольшой кадр 1931 года, годится только для миниатюры.
- Пластинка VAR! показана в составе иллюстрации NASA/ESA (CC BY 4.0), а не оригиналом из архива Карнеги.
- Карта COBE DMR отсутствует на Commons в свободном виде; сцена использует фотографию спутника и схему спектра.
- Лицензии проверены по машинным метаданным Wikimedia Commons (поле LicenseShortName); перед публичным запуском стоит просмотреть страницы файлов вручную — ссылки есть в разделе «Изображения».
- Античность, Коперник, Ньютон — за пределами проверенной базы, в экспозицию не включены (см. ТЗ §6.2).
- Публикация на внешнем хостинге не входит в задание.
